# Global-News

A news aggregation and classification project using machine learning.

## Overview

This project analyzes and classifies global news articles. It uses Jupyter Notebooks for data exploration and LIME (Local Interpretable Model-agnostic Explanations) for model interpretability.

## Tech Stack

- Python
- Jupyter Notebook
- LIME (for model explanation)
- HTML (for visual outputs)

## Contents

- `GN.ipynb` - Main news analysis notebook
- `Global_News.ipynb` - Extended analysis
- `lime_explanation_sample_*.html` - LIME explanation visualizations
- `confusion_matrix.png` - Model performance visualization

## Getting Started

```bash
# Install dependencies
pip install jupyter lime scikit-learn pandas

# Launch notebook
jupyter notebook GN.ipynb
```
